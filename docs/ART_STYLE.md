# SALVAGE — 화풍 기준

그림을 뽑거나 고치기 전에 읽는다.

**화풍은 확정됐다.** 지금 그림체를 그대로 유지한다. 기획자가 요청하지 않으면 화풍을 바꾸는 시도를 하지 않는다.

---

## 1. 확정된 화풍

기준 그림은 `art/style_anchor/`에 고정해 두었다.

| 파일 | 내용 |
|---|---|
| `art/style_anchor/android.png` | 메카·안드로이드의 기준 (NX-07 시안 A 시트) |
| `art/style_anchor/human.png` | 사람의 기준 (미리네 시안 A 시트) |

새 그림은 이 두 장과 나란히 놓았을 때 같은 손으로 그린 것처럼 보여야 한다. 이 폴더의 그림은 고치거나 바꾸지 않는다.

| 항목 | 내용 |
|---|---|
| 선 | 굵은 검정 잉크 외곽선. 실루엣은 굵게, 안쪽은 가늘게 |
| 형태 | 둥글게 정리한 매끈한 덩어리. 모서리를 평면으로 깎지 않는다 |
| 메카 디테일 | 패널 라인, 관절 구조, 통풍구, 발광 띠, 스텐실 숫자가 충분히 들어간다 |
| 비례 | 큼직한 건틀릿과 부츠, 어두운 보디슈트의 가는 몸통·윗팔·허벅지, 큰 헬멧 |
| 명암 | 그라데이션 없는 2단 셀 셰이딩. 기본색 + 경계가 또렷한 그림자 한 단계 |
| 하이라이트 | 장갑·헬멧·머리카락 위의 작고 또렷한 흰 창 모양, 가장자리의 가는 반짝임 |
| 색 | 지금 시트의 밝기와 채도 그대로. 더 진하게도, 더 따뜻하거나 차갑게도 하지 않는다 |
| 눈 | 지금 시트의 눈 그대로. 굵은 윗 속눈썹 선의 큰 눈 |

## 2. 그림체를 유지하는 방법

지금 그림체는 네 가지가 함께 만든 것이다. 하나라도 바뀌면 그림체가 달라진다.

1. **기준 그림** — `art/style_anchor/`의 시트를 참조 이미지로 넣는다.
2. **화풍 설명** — `art/prompts/_style_illustration.txt`
3. **화풍 고정 문구** — `art/prompts/_style_lock.txt`. 각지게 깎지 말 것, 디테일을 줄이지 말 것, 눈과 색을 바꾸지 말 것을 적어 두었다.
4. **모델과 크기** — `openai/gpt-image-2.6/sunburst/edit`, 3072×2048, 품질 high

`tools/fal_image.py`에 `--keep-style`을 붙이면 이 네 가지가 자동으로 들어간다.

```bash
python tools/fal_image.py --keep-style android \
  --prompt-file art/prompts/<내용>.txt \
  --prompt-file art/prompts/_sheet_layout_android.txt \
  --ref reference/<디자인 참조>.png \
  --out art/concept/<이름>.png
```

- `--keep-style android` : 메카·안드로이드. `human` : 사람. `both` : 둘이 함께 나오는 그림.
- `--dry-run`을 붙이면 fal.ai를 호출하지 않고 무엇이 보내지는지만 보여 준다.
- 기준 그림은 참조 이미지 맨 뒤에 붙는다. 디자인 참조는 그 앞에 `--ref`로 넣는다.

**뽑은 뒤 확인할 것**

1. 기준 그림과 나란히 놓고 본다. 선의 굵기, 형태의 둥글기, 디테일의 양, 색의 진하기, 눈이 같은가.
2. 한글 글자를 확대해서 오타를 본다 (`tools/fix_hangul.py`).
3. 기존 게임이나 브랜드의 캐릭터·아이콘이 섞여 나오지 않았는가.

다르게 나왔으면 그 그림을 쓰지 않고 다시 뽑는다. 화풍 설명을 고쳐서 맞추려 하지 않는다.

## 3. 채택하지 않은 시도

두 번 화풍을 바꿔 봤고 기획자가 둘 다 채택하지 않았다. 그림과 프롬프트는 `art/concept/archive_v2/`, `art/prompts/archive_v2/`에 보관한다. 다시 쓰지 않는다.

| 시도 | 한 일 | 기획자의 평가 |
|---|---|---|
| 2차 화풍 | `reference_그림체1~10.jpg`를 분석해 선·형태·비례·색을 모두 바꿔 시안 10장을 다시 그림 | "너무 각져있고, 메카 디테일이 떨어진다. 이전 화풍이 더 나았어." |
| 눈·색 시험 | 지금 시트에서 눈 그리는 방식과 색의 진하기만 바꾼 NX-07 3장 (큰 둥근 눈 / 겹고리 눈 / 날카로운 눈) | "샘플이 다 별로네. 그냥 현재 화풍으로 간다." |

**여기서 배운 것**

- 형태를 각지게 깎으면(모따기, 다면체, 뾰족한 조각) 안 된다.
- 단순화를 이유로 패널 라인과 관절 구조를 지우면 안 된다.
- 눈을 더 크게·더 날카롭게 바꾸거나 색을 더 진하게 올려도 좋아지지 않았다.
- 레퍼런스를 분석한 내용을 규칙으로 옮겨 적용하는 방식은 두 번 다 실패했다.
- 화풍을 건드릴 일이 생기면 한 장으로 먼저 보여 주고 확인받는다. 2차 화풍은 확인 없이 10장을 다 뽑은 것이 잘못이었다.

## 4. 레퍼런스에 대해

`reference/reference_그림체1~10.jpg`는 기획자가 좋아하는 화풍의 참고 자료이고, 다른 회사의 작품이다. 지금 그림체가 이 자료의 방향을 이미 담고 있다. 캐릭터 고유의 요소(특정 헬멧 모양, 머리 모양, 무기, 색 조합)는 가져오지 않는다.

측정해 둔 값 하나만 남긴다. 레퍼런스의 장갑 색은 채도가 80~95(HSV, 100점 기준)이고 지금 NX-07의 올리브는 33이다. 이 차이를 좁히려던 시도가 위의 눈·색 시험이다.
